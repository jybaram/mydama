# 마이담아 (MyDama)
마이담아 — 사진 자동 분류 PC 프로그램 (My Series)
흩어진 사진을 날짜·장소·인물별 앨범(폴더)에 나눠 담는 Windows PC 프로그램. My Series · 많이 담아.

**내려받기:** [최신 버전 MyDama.zip](https://github.com/jybaram/mydama/releases/latest/download/MyDama.zip)

1. ZIP 압축 풀기
2. Python 3.10 이상(64비트) 설치 — "Add python.exe to PATH" 체크
3. `설치.bat` 한 번 실행 (이때만 인터넷 필요)
4. 이후 `실행.bat`으로 사용

인터넷 없이 내 PC 안에서만 동작하며 사진이 외부로 전송되지 않습니다.
My Series: https://my.jybaram.workers.dev
